# 🪚 VIP Contratos

Aplicación web creada con **Streamlit (Python)** para generar **cotizaciones y contratos** de una empresa de cocinas integrales y muebles de alta gama.

---

## 🚀 Objetivo
Simplificar el trabajo del negocio generando cotizaciones automáticas, contratos y documentos en PDF/HTML, con despliegue en la nube de **Streamlit Cloud**.

---

## ⚙️ Instalación y ejecución rápida

Todo el flujo está automatizado mediante un **script maestro** que verifica el entorno, instala librerías y ejecuta la app.

### 1️⃣ Ejecutar script maestro
```bash
python entorno/iniciar_proyecto.py
